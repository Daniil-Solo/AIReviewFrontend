1. F1 - Аутентификация и Регистрация
   Суть: Гость может зарегистрироваться (запрос кода / подтверждение кода) и войти. Сохранение JWT в хранилище.
   Эндпоинты: POST /auth/register/start, POST /auth/register/confirm, POST /auth/login

2. F2 - Профиль пользователя
   Суть: Просмотр и редактирование своих данных (имя, email, смена пароля). Отображение текущего баланса кредитов.
   Эндпоинты: GET /users/{user_id}, PUT /users/{user_id} (предполагаем), GET /users/{user_id}/transactions (если есть)

3. F3 - Управление Рабочими Пространствами
   Суть: Создание пространства. Просмотр списка "Мои пространства". Редактирование названия/описания. Просмотр списка участников.
   Эндпоинты: POST /workspaces, GET /workspaces, PUT /workspaces/{id}, GET /workspaces/{id}/members

4. F4 - Приглашения и Вступление
   Суть: Создание ссылок-приглашений (slug, пароль). Вступление в пространство по ссылке. Управление ролями участников (кик, смена роли).
   Эндпоинты: POST /workspaces/{id}/join_rules, GET /workspaces/{id}/join_rules, POST /joins, PATCH /workspaces/{id}/members/{member_id}

5. F5 - Конструктор Критериев
   Суть: Создание, редактирование, удаление критериев оценки. Назначение тегов. Выбор типа (PROJECT_DOC/CODEBASE). Фильтрация списка.
   Эндпоинты: POST /criteria, GET /criteria, GET /criteria/available_tags, PUT /criteria/{id}, DELETE /criteria/{id}

6. F6 - Конструктор Задач
   Суть: Создание задачи внутри пространства. Привязка существующих критериев к задаче с указанием веса. Настройка флага экзамена.
   Эндпоинты: POST /tasks, GET /workspaces/{id}/tasks, POST /tasks/{id}/criteria, PATCH /tasks/{id}/criteria/{cid}, DELETE /tasks/{id}/criteria/{cid}

7. F7 - Сдача Решения (Студент)
   Суть: Выбор задачи. Загрузка ZIP-архива или ввод ссылки на GitHub. Просмотр списка своих решений со статусами (в процессе, готово, ошибка). Отмена загрузки.
   Эндпоинты: POST /solutions (multipart), GET /tasks/{id}/solutions, GET /solutions/{id}, POST /solutions/{id}/cancel

8. F8 - Просмотр результатов AI-ревью
   Суть: Отображение сгенерированной документации (ProjectDoc). Карточки проверок по критериям (пройдено/не пройдено) с комментариями ИИ. Вывод замечаний линтеров.
   Эндпоинты: GET /solutions/{id} (расширенная структура или доп. эндпоинты артефактов)

9. F9 - Интерфейс Экзамена
   Суть: Для студента: отображение вопросов, таймер, форма отправки ответов. Для преподавателя: просмотр ответов студента в деталях решения.
   Эндпоинты: GET /solutions/{id}/exam, POST /solutions/{id}/exam/answers (эндпоинты подразумеваются)

10. F10 - Финальный Вердикт Преподавателя
    Суть: Интерфейс для преподавателя: ввод оценки (0-100) и текстового комментария. Перевод решения в финальный статус "Оценено".
    Эндпоинты: PATCH /solutions/{id}/verdict (предполагаемый эндпоинт)

11. F11 - Панель Администратора
    Суть: Доступно только для is_admin=true. Просмотр списка всех пользователей, ручное пополнение баланса, создание новых администраторов.
    Эндпоинты: GET /users, POST /users/admin, POST /users/{id}/top-up
