СТРУКТУРНЫЙ ДИЗАЙН ПРОМО-СТРАНИЦЫ (LANDING PAGE)
ДЛЯ SaaS-ПЛАТФОРМЫ АВТОМАТИЗИРОВАННОЙ ПРОВЕРКИ УЧЕБНЫХ ПРОЕКТОВ

Контекст: Платформа как сервис для автоматической проверки студенческих работ с помощью ИИ.
Подходит для любых онлайн-курсов по программированию, особенно по Python и LLM-приложениям.
В основе — технология многоэтапного AI-ревью, генерации документации и экзамена по коду.

2. ПРОБЛЕМА И РЕШЕНИЕ (PROBLEM-SOLUTION)
─────────────────────────────────────────────────────────────────────────────
Левая колонка (проблема):
  ✗ Проверка работ по дисциплинами программной инженерии требует огромных временных затрат.
  ✗ Преподаватели перегружены, обратная связь задерживается на дни и недели.
  ✗ Студенты теряют мотивацию без своевременной обратной связи.
  ✗ При росте числа студентов масштабировать ручную проверку невозможно.

Правая колонка (решение):
  ✓ AI-ревью за 5–15 минут по любым критериям.
  ✓ Автоматическая генерация документации проекта.
  ✓ Встроенный экзамен по коду и слабым местам архитектуры.
  ✓ Преподаватель выставляет только корректирует финальный вердикт, экономя 80% времени.

3. КАК ЭТО РАБОТАЕТ (4 ШАГА)
─────────────────────────────────────────────────────────────────────────────
[1] Преподаватель подготавливает задачу
    Создает задачу, выбирает критерии оценки из доступных или создает свои

[2] Студент загружает решение
    Студент передает решение в виде ссылки на GitHub-репозиторий или загружает zip-файл

[3] ИИ проводит многоэтапную проверку
    ИИ генерирует проектную документацию, проверяет работу на основе критериев, использует инструменты статического анализа, готовит вопросы для экзамена и проводит его

[4] Преподаватель корректирует финальную оценку
    Преподавателю доступны все артефакты проверки, на основе которых он делает финальный вердикт

5. ДЛЯ КОГО ЭТА ПЛАТФОРМА (ЦЕЛЕВАЯ АУДИТОРИЯ)
─────────────────────────────────────────────────────────────────────────────
Табы / три карточки:

  Преподаватели и авторы курсов
    – Экономьте время на проверке.
    – Сосредоточьтесь на творческих аспектах обучения.
    – Получайте детальные отчёты по каждому студенту.

  Студенты
    – Получайте обратную связь за минуты, а не дни.
    – Улучшайте код с помощью AI-рекомендаций.
    – Проходите экзамен и видите свои ошибки.

  Руководители образовательных платформ и курсов
    – Масштабируйте проверку на сотни студентов.
    – Снижайте нагрузку на преподавательский состав.
    – Повышайте честность оценок через экзамен.

7. ПРИМЕР РЕЗУЛЬТАТА (ДЕМО ОТЧЁТА)
─────────────────────────────────────────────────────────────────────────────
Покажите карточку решения с вкладками:

  [ Проектная документация ] [ Критериальная проверка ] [ Статический анализ ] [ Экзамен ]

  Пример содержимого вкладки Критериальная проверка:
    ✅ Критерий «Архитектура» — пройден (комментарий: хорошее разделение слоёв)
    ⚠️ Критерий «Документация» — частично (нет docstring у трёх функций)
    ❌ Критерий «Безопасность» — не пройден (Bandit нашёл уязвимость)

  + Кнопка «Посмотреть полный отчёт» → ведёт на демо-страницу.
